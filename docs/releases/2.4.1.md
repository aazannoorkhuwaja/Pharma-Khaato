# Pharma Khaato 2.4.1

This build fixes the fifteen findings from the pharmacy recording review.

Choose **Pharma-Khaato-2.4.1-Setup-Windows-x64.exe** for Windows, **Pharma-Khaato-2.4.1-linux-amd64.deb** for Ubuntu/Linux Mint, or **Pharma-Khaato-2.4.1-linux-x86_64.tar.gz** for compatible Linux desktops. Python is not required.

## Changes you will notice

- Readable stock forms in dark mode, a wider receiving panel, and expiry labels that match the chosen date format. The date calendar starts in the current month without inventing an expiry date.
- Bill total and change stay beside Complete Sale. Customer selection shows the customer's name without a generated reference.
- The footer updates when a cash shift opens or closes. Closing requires a confirmed count and acknowledgement of any difference. The latest saved closing summary remains available after restarting.
- Optional medicine details can be expanded when needed. Setup prefills your username for sign-in and opens a supplier/medicine/stock/cash preparation checklist.
- Search explains whether a medicine is missing or has no stock available for sale. Empty supplier accounts offer Add First Supplier; customer credit explains how accounts appear.

## Installation and existing records

Finish pending operations and make a backup before updating. Close the app on every counter. Reinstall using the same operating-system user and installation method. Shop records and passwords are preserved; there is no default login password.

The interface is English. Windows and Linux x64 are supported. More than one counter requires a running shop computer and local network.

## Release acceptance

This release is prepared as a **draft** until native CI and the pharmacy acceptance checklist are complete. Consult `release.json` for the exact commit, `SHA256SUMS` for download verification and `Windows-SIGNING.txt` for signing status. A draft is not an approved production release.

Test the actual receipt printer and scanner, complete the practice flow in [TRY_IT.md](https://github.com/aazannoorkhuwaja/Pharma-Khaato/blob/main/docs/TRY_IT.md), and record the result before real sales. Do not disable operating-system protection to run an unsigned installer.
