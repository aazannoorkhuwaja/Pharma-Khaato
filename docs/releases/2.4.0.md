# Pharma Khaato 2.4.0

An offline pharmacy billing app, built and led by **Azaan Noor Khuwaja**, with contributions from **Atif Khan**.

## Which file do I download?

| Your computer | Download |
| --- | --- |
| Windows 10 (1809 or newer) or Windows 11, Intel/AMD 64-bit | **Pharma-Khaato-2.4.0-Setup-Windows-x64.exe** |
| Ubuntu 22.04/24.04 or compatible Linux Mint, Intel/AMD 64-bit | **Pharma-Khaato-2.4.0-linux-amd64.deb** |
| Other compatible Linux desktops, or installation without administrator access | **Pharma-Khaato-2.4.0-linux-x86_64.tar.gz** |

Python is not needed. Download the matching **START-HERE** guide if you need help. GitHub's “Source code” downloads are for developers.

## What can I do?

- Make bills by scanning a barcode or searching for a medicine.
- Sell tablets, strips and boxes; check stock and expiry dates.
- Take cash, card, Easypaisa, JazzCash or credit payments.
- Record customer dues, payments, returns and supplier bills.
- Open and close the cash drawer's daily record and make local backups.

Cash customers can stay as Walk-in. No name, phone or CNIC is needed.

## Reliability changes

- Repeating a submitted bill returns the saved sale, preventing duplicate stock deductions.
- Digital payments stay separate from physical drawer cash.
- Backup restoration and temporary-file cleanup fixes address failures found on Windows.
- Test windows are fully released before shutdown, fixing intermittent Qt crashes.
- Both operating systems have packaged-app checks. Reinstallation keeps shop records.
- Update notices show the fixes and let you choose when to download. Nothing installs itself.

## Before using it for real sales

Create a practice shop on a spare computer. Follow the short pharmacy test linked from the README, then test your actual receipt printer and scanner. The owner must check tax settings, opening stock, cash and customer/supplier balances. Keep a verified backup on another device.

The interface is English. Urdu and Sindhi are planned after the pharmacy trial. ARM computers, independent offline counter sales, internet branch synchronisation and automatic FBR reporting are not included. More than one counter needs a running main shop computer and local network.

## Updating an existing shop

Finish or hold bills, confirm pending operations, close every counter and make a backup before installing. Use the same installation method and Windows/Linux user as before. Do not update the main shop computer while another counter is working. Shop records and backups stay on your computer during reinstall or uninstall.
