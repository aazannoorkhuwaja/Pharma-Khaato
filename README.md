# Pharma-Khaato: Surgical Inventory & Credit RDBMS

## Project Description
A specialized POS system for surgical pharmacies to manage batch-specific inventory and traditional customer credit ledgers (Khaatos). The system ensures data integrity for multi-item billing and maintains an immutable audit trail of customer debt. It replaces manual paper-based record-keeping with a relational database that automates running balance calculations and expiry-based stock alerts.
