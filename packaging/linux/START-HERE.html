Start using Pharma Khaato

Make pharmacy bills without internet. Python is not needed.

Install on Ubuntu or Linux Mint

Download the file ending in linux-amd64.deb from the official release. Open it with your system’s software installer and choose Install. Then open Pharma Khaato from the applications menu. Installation needs the computer owner’s password.

Install without an administrator password

Download the linux-x86_64.tar.gz file and extract it. Open a terminal inside that extracted folder and run ./install.sh. Open Pharma Khaato from the applications menu. This option may need a technician to install Linux desktop libraries first.

Your first use

Create the owner account and keep its password safe. Check the shop name, receipt printer and tax settings. Add some practice stock and follow the short practice test before real sales.

Updates and backups

Finish your work and close the app on every counter. Make a backup in Settings and keep a copy on another device. Install the newer package using the same installation method. Your shop records stay separate from the app and are kept during reinstall and uninstall.

Removing a .deb package uses your system’s software manager. For the extracted version, run ./uninstall.sh from the download folder. Do not delete the shop data folder to remove the app.

Supported build: 64-bit Intel/AMD Linux, Ubuntu 22.04/24.04 and compatible desktop systems. ARM is not supported. Test your own printer and scanner before relying on the app.
