Start using Pharma Khaato

For Windows 10 (version 1809 or later) and Windows 11, 64-bit Intel/AMD computers. You do not need Python, Linux or a terminal.

Use this build for supervised pharmacy testing first. Check your actual scanner, printer, stock and cash totals before using it for live sales. Urdu and Sindhi interfaces are planned after pharmacy feedback.

1. Install and open

  1. Get the versioned Setup-Windows-x64.exe from the person supplying your build. Close the old app before installing an update.
  2. Double-click Setup and follow the installer. Keep the desktop shortcut selected. A normal per-user install does not require an administrator password.
  3. Open Pharma Khaato from your desktop or Start menu. Use the same Windows user account every day: shop data belongs to that Windows account.
  4. If Windows blocks the download or publisher is unrecognised, ask the person supplying the build to verify it. Do not disable antivirus or Windows security. This test build may not yet be code-signed.

2. Owner setup

  1. Create your owner account and keep the password private. Give each cashier a separate staff account.
  2. Open Settings. Save your real shop details and check the sales tax percentage with the owner/accountant. A value of 1 means 1%.
  3. Connect the scanner and install the printer manufacturer's Windows driver. In Printer Setup, choose the correct printer and paper width, then print a test receipt.
  4. Add medicines and real stock. Check whether each barcode means a tablet, strip, box or sealed pack. Verify opening stock and customer/supplier dues before switching to real sales.
  5. Choose an external backup location on the main shop computer. Keep a second copy on another physical device and practise restore with support on a spare installation.

3. Cashier's daily work

  1. Sign in and open a shift with the actual cash in the drawer.
  2. Scan or search a medicine, confirm strength and unit, then choose payment. Cash customers can stay Walk-in; personal details are unnecessary.
  3. For credit, choose the correct customer. A name is enough; phone helps distinguish similar names and CNIC is optional.
  4. Check cash received and change. Confirm the bill once. If the result is uncertain, confirm the pending bill before creating another one.
  5. A printer error does not mean the sale failed. Fix the printer and reprint the saved bill.
  6. Use Hold to save unfinished work. At closing, count cash and close the shift. Card/Easypaisa/JazzCash are separate from drawer cash.

Optional updates and builder credits

Open About Pharma Khaato to see the builders, check for updates or disable automatic checks. When internet is available, the app can show a newer version and its fixes. Choose Later to keep working, or open the official download page. Nothing installs automatically. Back up and stop shop work before running a new Setup.

Keep your shop records safe

Data is normally in %LOCALAPPDATA%\Pharma-Khaato. Updates and uninstall do not intentionally remove it. Reinstalling Windows, changing Windows accounts or losing the computer can still lose access: keep verified external backups. Never delete that folder to solve a sign-in problem.

One computer can work without internet. Multiple counters need the main shop computer and local router running. Ask your technician to set up Shop Computers; never put the live database in a shared network folder.

What to tell the person testing this build

Write down the task you tried, what happened, the exact message and the app version. Report confusing labels or steps as well as errors. Avoid sending customer records or passwords in screenshots. Test ten bills, a held bill, credit repayment, return, closing cash and a printer reconnection.
